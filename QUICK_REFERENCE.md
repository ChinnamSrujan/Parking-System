## Stop/Start Commands

### Stop Servers
Press `Ctrl+C` in each terminal window

### Start Backend
```bash
cd smart-parking-backend
mvn spring-boot:run
```

### Start Frontend
```bash
cd smart-parking-frontend
npm run dev
```

## Quick Test Flow
1. Open http://localhost:3000
2. Login as user
3. Click "Search Parking"
4. Click "View Slots" on any lot
5. Click a green slot
6. Complete booking
7. Check "My Bookings"
